# PHP: соглашения

- `declare(strict_types=1);` — первой строкой в каждом файле.
- Классы — в namespace `App\`, PSR-4 автозагрузка.
- Один класс на файл, имя файла = имя класса.
- Типизируй параметры и возвращаемые значения (`: string`, `: void` и т.д.).
- Именование: `camelCase` — методы/переменные, `PascalCase` — классы,
  `SCREAMING_SNAKE_CASE` — константы.
- Не оставляй `var_dump` / `print_r` / `die()` в правках.
- Синтаксис проверяется автолинтом (`php -l`) — правь ошибки сразу.
- PHP 8+: используй `match`, конструктор-промоушен свойств, `readonly`,
  именованные аргументы там, где это упрощает чтение.
- Стиль — PSR-12 (4 пробела, лимит строки ~120); форматирование — PHP-CS-Fixer,
  статанализ — PHPStan/Psalm (`phpstan analyse`, `psalm`).
- Импорты — через `use`, без wildcard; порядок и группировка — по проекту.
- Публичный API документируй PHPDoc.
