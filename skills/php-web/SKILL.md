# PHP: веб-приложения

## Безопасность (обязательно)
- SQL — только через подготовленные выражения (PDO/ORM). Никакой склейки
  строк в запрос: `prepare()` + параметры.
- Вывод в HTML — через `htmlspecialchars($v, ENT_QUOTES, 'UTF-8')`
  или шаблонизатор с автоэкранированием (Twig/Blade). Это защита от XSS.
- Формы и состояние меняем через POST + CSRF-токен. Проверяй токен на сервере.
- Пароли — `password_hash()` / `password_verify()`. Никакого md5/sha1.
- Файлы и пути пользователя не подставляем в `include`/`fopen` напрямую.
- Никаких секретов в коде: `.env` / переменные окружения.

## Структура и роутинг
- Логика — отдельно от представления: контроллеры/сервисы, шаблоны — в `templates/`.
- Валидация входных данных выполняется до обращения к слою данных.
- HTTP-ответы возвращаем корректными статусами (404, 422, 500), а не всегда 200.
- Фильтрация/подготовка данных — до шаблона, в шаблоне только вывод.

## Проект
- Если проект на фреймворке (Laravel/Symfony) — следуй его конвенциям
  (артизан-команды, миграции, сервис-контейнер), не изобретай своё.
- Статика: подключай через сборку (Vite/Mix) или отдельные `assets/`, а не инлайном.
